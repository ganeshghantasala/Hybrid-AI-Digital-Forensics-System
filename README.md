\# Hybrid Explainable AI-Based Digital Forensics System



\## Overview

This project is a Hybrid Explainable AI-Based Digital Forensics System designed to automate suspicious file detection, evidence recovery, and forensic reporting.



\## Features

\- Suspicious file detection using Machine Learning and rule-based analysis

\- Entropy analysis for encrypted or obfuscated files

\- SHA-256 hashing for evidence integrity

\- Explainable AI module for transparent decision-making

\- Basic Recycle Bin recovery

\- Basic Signature-based disk carving

\- Tamper-evident forensic ledger

\- Interactive dashboard and report generation



\## Technologies Used

\- Python

\- CustomTkinter

\- Scikit-learn

\- NumPy

\- Matplotlib

\- FPDF
